# 🏦 Online Banking System

> **A simple and secure Java-based banking management system for managing accounts and transactions.**

Online Banking System is a Java application developed to simulate core banking operations such as account management, balance handling, and financial transactions.

The project demonstrates how Java, JDBC, MySQL, and object-oriented programming concepts can be combined to build a functional banking application.

## ✨ Features

- 👤 **User Management**
  - Create and manage customer information
  - Access user account details

- 🏦 **Account Management**
  - Create and manage bank accounts
  - View account information and balances

- 💰 **Transactions**
  - Deposit money
  - Withdraw money
  - Transfer funds
  - Track transaction details

- 📋 **Transaction Records**
  - Store transaction information
  - Retrieve transaction history

- 🗄️ **Database Integration**
  - Persistent storage using MySQL
  - JDBC-based database connectivity

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Java | Application development |
| JDBC | Database connectivity |

| OOP | Application architecture |
